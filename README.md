Tech Resume Engine v3.0 | Premium Edition

Construtor de currículos modernos e profissionais focado em desenvolvedores e profissionais de tecnologia.

Uma aplicação web single-page, 100% no navegador, com preview em tempo real, personalização visual e exportação para PDF de alta qualidade.

## ✨ Funcionalidades

- **Preview em tempo real** — tudo que você digita aparece instantaneamente no currículo
- **Personalização visual**
  - Cor de destaque (accent color) com seletor
  - 3 tipografias: Plus Jakarta Sans, Space Grotesk e JetBrains Mono
  - Upload de foto de perfil + ajuste de posição vertical
- **Seções completas**
  - Identidade profissional (nome, cargo, email, telefone, localização, GitHub)
  - Resumo / Objetivo profissional
  - Hard Skills e Soft Skills
  - Formação acadêmica (dinâmica — adicione quantas quiser)
  - Projetos (dinâmicos)
- **Exportação PDF** de alta resolução (A4) via html2pdf.js
- **Zoom** do preview
- **UI moderna** com glassmorphism, dark mode e animações suaves
- **100% offline** após carregar (exceto CDNs)

## 🚀 Como usar

1. Abra o arquivo `index.html` em qualquer navegador moderno
2. Preencha as informações no painel esquerdo
3. Personalize a cor e a fonte
4. Adicione formações e projetos clicando em **+ Adicionar**
5. Clique em **Baixar PDF** para gerar o currículo

> Dica: use o zoom no preview para visualizar melhor o layout antes de exportar.

## 🛠️ Tecnologias

- HTML5 + CSS3 + JavaScript (Vanilla)
- [Tailwind CSS](https://tailwindcss.com/) (via CDN)
- [html2pdf.js](https://github.com/eKoopmans/html2pdf.js)
- [Phosphor Icons](https://phosphoricons.com/)
- Google Fonts (Plus Jakarta Sans, Space Grotesk, JetBrains Mono)
